# Safr - Browser Extension
Safr is a security-focused browser extension designed to help users navigate the web more safely. This extension provides features such as protection against phishing, alerts for potentially malicious sites, and other security tools to enhance your browsing experience.

## Features
* Phishing Protection: Safr detects and warns you about phishing attempts and unsafe websites.
* Malware Alerts: Stay safe with alerts about websites that could contain malware or harmful content.
* Privacy Controls: Manage your privacy settings easily and control what information websites can access.
* User-Friendly Interface: Designed with simplicity and ease of use in mind.
## Installation
### Option 1:
1. Clone the Repository

``` git clone https://github.com/yourusername/safr-extension.git ```

2. Load the Extension in Your Browser
Open Chrome and navigate to chrome://extensions/.
Enable Developer mode in the top right corner.
Click on Load unpacked.
Select the safr-extension directory you just cloned.

4. Use Safr
Once installed, you should see the Safr icon in your browser's toolbar. Click on the icon to access the features of the extension.

### Option 2:
1. Download the Extension
Go to the Safr GitHub repository.
Click on the green Code button.
Select Download ZIP.

3. Unzip the File
Find the downloaded safr-extension.zip file in your Downloads folder.
Right-click on the file and select Extract All... to unzip it.

5. Load the Extension in Your Browser
Open Chrome and navigate to chrome://extensions/.

Enable Developer mode in the top right corner.
Click on Load unpacked.
Navigate to the unzipped safr-extension folder and select it.

7. Use Safr
You should now see the Safr icon in your browser's toolbar. Click on the icon to start using the extension.
